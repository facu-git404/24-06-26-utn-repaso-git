## ¿Que es?

Estandar de como manejar un repositorio colaborativo

## ¿Que haremos?

Aprenderemos a manejar un repositorio colaboratorio

Nunca trabajaremos en la rama main para hacer cambios, ya que esto puede generar muchos errores, para eso creamos una rama llamada development

Para crear la rama de desarrollo debemos usar este comando:

git checkout -b <nombre-nueva-rama>
